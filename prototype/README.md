# RentAgent 高保真原型系统（React 实现）

> 对应文档：《04-原型工具使用方法》v1.1 页面规划清单（22 页）· 《06-原型设计评审报告》复审条件
> 说明：本原型为**纯前端 Mock 演示**，无后端、无真实大模型；AI 能力以规则匹配模拟，数据刷新后重置。

## 一、快速启动

```bash
cd prototype
npm install        # 首次运行
npm run dev        # 开发模式 → http://localhost:5173
```

生产构建与预览：

```bash
npm run build
npm run preview    # → http://localhost:4173
```

**技术栈**：React 18 + Vite 5，无 UI 组件库、无路由库（自实现 hash 路由）。
注意：原型采用 React 仅作为快速演示载体；**项目正式技术栈基线仍为《02-项目最终确认书》所确认的 Vue 3 + Element Plus**，原型不构成技术栈变更。

## 四、建议演示路径（约 5 分钟）

1. **租客线**：P00 快捷登录小陈 → P01 查看 AI 历史推荐（推荐依据横幅 + 卡片推荐理由 + 最近浏览）→ 点开一套新房源再返回 P01，观察推荐随历史变化 → P02 切地图模式 → P03 收藏并预约看房 → P04 问"预算 3000，要两居，最好近地铁"再点"再便宜一点" → P06 点击红色风险条款看 AI 解读 → 双方签约 → P07 查看消息与租约、对已完成合同发表评价。
2. **房东线**：P00 登录王房东（未实名）→ P10 被拦截 → P14 完成实名 → P10 发布房源（点"AI 识别填充"看上传+识别过程与结果卡、获取 AI 定价）→ P11 查看待审核状态。
3. **管理线**：P00 登录管理员 → P21 审核工作台（风险分 82 的高风险房源已置顶，展开 AI 疑点后驳回并填理由）→ P22 禁用"历史用户" → 回 P00 验证其无法登录 → P23 新增一条 FAQ → 切回租客在 P04 提问验证。

## 五、目录结构与实现说明

```
prototype/
├── index.html          # Vite 入口
├── package.json
├── vite.config.js
└── src/
    ├── main.jsx        # 挂载入口
    ├── App.jsx         # 路由表 / RBAC 守卫 / 顶栏 / Toast
    ├── store.jsx       # 全局状态（会话、Toast）+ 数据操作（actions）
    ├── data.js         # Mock 数据（用户/房源/预约/合同/FAQ/统计）
    ├── ai.js           # AI 模拟：找房解析（FR-12）、FAQ 命中（FR-13）
    ├── ui.jsx          # 共享组件 + P00 + 页面目录
    ├── tenant.jsx      # 租客端 P01~P07 及状态页
    ├── landlord.jsx    # 房东端 P10~P14
    ├── admin.jsx       # 管理端 P20~P23
    └── styles.css      # 全部样式（主色 #1F6FEB）
```

**已知边界（与范围基线一致）**：AI 为规则模拟不连接大模型；验证码为固定 Mock 值；租金仅做账单记录不对接支付；签约不接 CA 电子签章；地图为示意画布非真实地图服务；数据刷新即重置（会话身份保留于 localStorage）。
