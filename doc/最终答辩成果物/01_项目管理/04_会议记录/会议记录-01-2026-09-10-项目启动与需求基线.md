## 一、会议议题

1. 项目立项背景与"对话即服务"定位确认；
2. 需求范围清单（FR-01 ~ FR-23）逐项过会，明确本期范围与范围外内容；
3. 技术选型与总体架构方案（前后端分离 + 智能体层）；
4. 团队成员分工与里程碑节点确认。

## 二、会议结论

1. **项目定位**：将租赁业务全流程（找房、预约、签约、账单、评价、审核）与大模型智能体结合，
   提供"对话即服务"交互体验；智能体是本次课程设计的核心亮点。
2. **技术栈确定**：前端 React 18 + TypeScript + Vite 5 + Ant Design 5；后端 Spring Boot 3.3 + MyBatis-Plus
   + LangChain4j；数据 MySQL 8 + Redis 7。AI 层不绑定单一厂商，采用协议适配网关。
3. **需求范围**：通过需求定义说明书第三章范围清单，按模块标注 FR 编号；凡明确列在范围外的需求本期不做。
   本期先保 P0 业务闭环（实名 → 发布 → 审核 → 预约 → 签约 → 账单），AI 能力按 P0/P1 分级交付。
4. **团队分工**（5 人）：
   - 王硕：项目负责人 / 后端（统筹、里程碑、后端业务模块）
   - 邓颢琛：后端 / AI 工程（LLM 网关、RAG 知识库、智能体编排）
   - 张卫雨：前端（租客端 / 房东端页面）
   - 陈玄晔：前端 / 测试（管理端页面、测试用例与缺陷跟踪）
   - 李天泽：文档 / 数据（文档编写、数据库设计、数据字典、知识库 FAQ）
5. **里程碑**：需求定义 9 月中旬完成 → 概要设计与数据库设计 → 两轮迭代开发 → 集成测试与验收。
