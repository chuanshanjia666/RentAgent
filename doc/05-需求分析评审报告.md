## 四、发现问题清单

严重级别定义：**S1** 阻塞进入下一阶段；**S2** 一般，须在进入概要设计前修订；**S3** 建议，酌情采纳。

| 编号 | 级别 | 问题位置 | 问题描述 | 修改建议 |
| ---- | ---- | -------- | -------- | -------- |
| R-01 | S2 | 03§4.3 ↔ 02§3.1 | 确认书范围内承诺"关键词搜索"，但矩阵中无对应 FR 条目（FR-09 描述仅含多条件筛选组合），存在范围项无需求承载的追溯断链 | 在 FR-09 描述中补充关键词搜索，或新增独立 FR（含分词/模糊匹配与验收标准） |
| R-02 | S2 | 03§四 ↔ 03§三 / 04§4.1 | 租客核心场景含"收藏房源"、原型规划 P07 含收藏 Tab，但矩阵无收藏类 FR，需求-原型追溯断链 | 新增"房源收藏管理"FR（建议 P1），明确收藏/取消/列表入口 |
| R-03 | S2 | 02§2.2 ↔ 03§四 | 确认书目标 1 的核心闭环含"评价"（FR-20 为 P1）、目标 2 要求"4 项 AI 核心能力上线"（其中 FR-14/15 为 P1 可降级），可度量目标（硬性）与 MoSCoW（弹性）口径不一致 | 统一口径：或在确认书注明"其中 FR-14/15 按 P1 交付，演示前必须完成"；或将 FR-14/15 升级 P0 |
| R-04 | S2 | 03§4.3 FR-11 | 验收标准"同一用户重复访问推荐结果趋于收敛"不可操作、不可测 | 改为可量化标准，如"同一用户 24 小时内重复访问，推荐列表重合度 ≥ 60%"或给出推荐点击率（CTR）指标 |
| R-05 | S2 | 03§4.4 FR-13 | 验收标准"回答准确"无判定方法，"命中知识库"与"准确"的界限未定义 | 建立评测集（≥30 条代表性问题 + 标准答案），定义判定规则（如人工评分准确率 ≥ 90%，或关键词命中规则） |
| R-06 | S3 | 03§4.4 FR-12 | 验收标准"10 条典型需求语句全部正确解析并返回有效房源"中"正确解析""有效房源"未定义判定口径 | 附典型语句清单与判分表（解析出的结构化条件与预期一致；返回 ≥1 条相关房源即视为有效） |
| R-07 | S3 | 03§4.1 FR-01 | 注册采用"手机号+验证码"需接入短信服务商，与"经济可行性：成本极低"的结论需对齐；课程项目通常无短信额度 | 明确验证码通道方案：对接服务商免费额度 / 邮箱验证码 / 开发期 Mock 验证码（演示环境固定码） |
| R-08 | S3 | 03§4.5 FR-18 | 合同"自动填充双方信息"，但租客是否需实名认证未定义（FR-03 仅约束房东），合同主体信息来源不明确 | 明确租客签约前信息要求（至少姓名+联系方式；是否实名二选一并写入矩阵） |
| R-09 | S3 | 03§六 | 映射总览按"业务域"分组，而功能矩阵按"能力模块"分组（FR-14/15 归 AI 模块但映射至交易与合同），口径差异易误读 | 在第六节加注口径说明，或调整映射表使两处分组维度一致 |
| R-10 | S3 | 03§二 | 需求获取方法为"计划"，访谈与竞品分析的过程记录未见归档，评审缺少过程证据 | 补充访谈纪要摘要与竞品分析对照表，作为附录归档 |
| R-11 | S3 | 03§五 | NFR-07"可用率 ≥ 99%"未定义统计口径（时段、度量方式）；未覆盖数据备份/恢复要求 | 明确演示期可用率统计方式；可增设数据备份 NFR（每日全量备份，P3/P1 酌情） |
| R-12 | S3 | 02§2.2 ↔ 03§五 NFR-01/02 | 确认书目标 3 的性能口径（"响应时间 ≤ 2 秒"）与 NFR-01 条件口径（"95% 接口 ≤ 2s、并发 50"）不完全一致，且未引用编号 | 确认书目标改为引用 NFR-01/02 编号，避免双处维护 |

**统计**：S1 × 0，S2 × 5（R-01~R-05），S3 × 7（R-06~R-12）。

## 五、评审结论

**结论：有条件通过。**

1. 需求矩阵整体质量良好：编号/追溯/变更体系健全，P0 集合可构成最小可行产品，AI 特色需求（FR-12~16）与项目定位一致，验收标准总体可测；
2. **通过条件**：S2 项（R-01~R-05）须在进入概要设计阶段前完成修订，并更新《03-需求分析矩阵》版本号（v1.1）及变更记录，按《02-项目最终确认书》第九条走变更流程；
3. S3 项（R-06~R-12）由项目负责人组织评估，酌情采纳；
4. 修订确认后，需求基线（v1.1）作为《概要设计》《接口文档》《测试用例》的输入。

> 整改跟进（2026-09-04）：S2 项已全部落实——《03-需求分析矩阵》已修订发布 **v1.1**（新增 FR-25、NFR-10，修订 FR-01/09/11/12/13/18、NFR-07 及第二、六节口径注），《02-项目最终确认书》已修订发布 **v1.1**（可度量目标口径注）。
