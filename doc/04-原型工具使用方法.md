# RentAgent 原型设计工具使用方法

> 项目名称：RentAgent —— 基于 AI 智能体的房屋租赁系统
> 文档版本：v1.1
> 编写日期：2026-09-03（v1.1 修订日期：2026-09-04，按《06-原型设计评审报告》补齐页面规划）
> 用途：指导项目组成员使用原型工具完成 RentAgent 三端（租客端 / 房东端 / 管理端）的高保真原型设计与评审。

---

## 一、为什么要做原型

在编码前制作可交互原型，目的在于：

1. **验证需求**：对照《需求分析矩阵》逐条检查每个 FR 是否有对应页面与交互承载；
2. **提前暴露问题**：页面跳转、状态流转（如房源"待审核→已上架→已下架"）在原型阶段修改成本最低；
3. **统一认知**：开发、测试、答辩评审都以原型为视觉基准，避免"理解偏差返工"；
4. **支撑演示**：答辩/评审时可直接演示可点击原型，代替静态图讲需求。

## 三、墨刀使用方法（分步教程）

### 3.1 准备工作

1. 访问墨刀官网 `modao.cc`，注册/登录（支持手机号或微信）；
2. 进入工作台 →【新建】→ 选择 **"Web 项目"**（本项目为 B/S 系统；若后续做移动端演示再建 App 项目）；
3. 画布尺寸选择 **1440 × 900**（常见桌面分辨率），项目命名：`RentAgent-高保真原型`。

### 3.2 认识工作界面

| 区域 | 位置 | 作用 |
| ---- | ---- | ---- |
| 页面面板 | 左侧 | 管理所有页面，支持文件夹分组（按端/按模块分组） |
| 组件库 | 左下/左侧 | 预置按钮、输入框、表格、导航栏等组件，拖拽即用 |
| 画布 | 中间 | 页面绘制区，可多页面并行排列 |
| 属性面板 | 右侧 | 设置选中元素的尺寸、颜色、圆角、阴影等样式 |
| 大纲/交互 | 右侧 Tab | 管理页面内交互事件与跳转链接 |

### 3.3 基本操作五步法

**第 1 步：搭框架**
- 从组件库拖入【顶部导航栏】【页脚】到画布，设置主色 `#1F6FEB`（可自定义）；
- 使用"母版"功能（页面面板 → 母版）：把导航栏做成母版，所有页面复用，改一处全局生效。

**第 2 步：铺内容**
- 拖入文本、图片、卡片、输入框、按钮等组件完成页面主体；
- 用【数据填充】功能（选中组件 → 右键 → 数据填充）可一键填充假名字、假图片，快速做出"真实感"；
- 房源卡片建议做成一个"组件组合"，复制后修改文案即可批量铺列表页。

**第 3 步：设交互（让原型"动"起来）**
- 选中按钮/链接 → 右侧【交互】面板 → 新建事件；
- 常用事件组合：
  - `单击` → `跳转到页面`（如"房源卡片 → 房源详情页"）；
  - `单击` → `显示/隐藏`（如"筛选面板展开"、"AI 对话抽屉弹出"）；
  - `输入` → `状态改变`（模拟搜索框交互）；
- 底部导航每个 Tab 分别链接到对应页面，形成可点击闭环。

**第 4 步：加状态说明**
- 对同一页面的不同状态（如房源"待审核 / 已上架 / 已驳回"），复制页面并在页面名后缀注状态：`P-房源详情-已驳回`；
- 用便签组件（Sticky Note）在画布旁标注该页对应的需求编号（如"承载 FR-05 / FR-08"），方便与《需求分析矩阵》核对。

**第 5 步：预览与分享**
- 点击右上角【演示/预览】进入运行模式，实际点击验证跳转逻辑；
- 点击【分享】生成链接，发给组员与指导老师评审；评论功能可直接在页面上批注修改意见。

### 3.4 效率技巧

| 技巧 | 说明 |
| ---- | ---- |
| 组件库市场 | 墨刀自带"资源广场"，搜索"后台管理""电商列表"可直接套用整套模板 |
| 快捷键 | `Ctrl+D` 复制元素；`Ctrl+G` 成组；`Ctrl+滚轮` 缩放画布 |
| 页面编号 | 页面统一用 `P序号-端-页面名` 命名（如 `P05-租客端-房源详情`），便于文档引用 |
| 版本管理 | 重大修改前使用"历史版本"备份，避免评审意见覆盖后无法回退 |

## 五、原型评审流程

1. **自查**：绘制完成后，对照《需求分析矩阵》逐条核对——每个 P0 需求是否至少有一个页面承载、跳转闭环是否完整；
2. **组内评审**：分享链接给全体组员，按"页面 → 交互 → 状态"三步走查，意见直接在原型上批注；
3. **修订定稿**：集中处理批注意见，形成 `v1.0-定稿` 版本；
4. **进入开发**：定稿原型作为 UI 还原基准，开发阶段如需改动，按《项目最终确认书》第九条变更流程执行。

## 六、常见问题（FAQ）

| 问题 | 处理办法 |
| ---- | -------- |
| 免费版项目数量/协作者不够 | 一个项目内用"页面文件夹"区分三端即可；或将定稿导出图片另建演示项目 |
| 表格、图表组件不好画 | 后台类页面优先使用资源广场的"后台管理"模板，统计图表可先用静态占位图 |
| AI 对话流效果难模拟 | 用"聊天气泡"组件 + `显示/隐藏` 交互模拟消息逐条出现即可，不必真连大模型 |
| 需要在代码评审中引用原型 | 分享链接支持定位到具体页面，可在 README / Issue 中直接粘贴带锚点的链接 |
